# TOTP-коды в Telegram

GitHub потребовал второй фактор для входа. Мне понадобилось место, где можно хранить и получать одноразовые коды на разных устройствах, не устанавливая отдельное приложение. Так я решил сделать бота для Telegram.

[Бот @totp_widgets_bot](https://t.me/totp_widgets_bot) создаёт карточки с TOTP-кодами прямо в переписке. Отправьте ему ссылку настройки `otpauth://` или название и секретный ключ двумя строками. В ответ бот создаст виджет; название карточки можно найти обычным поиском по чату.

Ключ хранится в данных сообщения Telegram. Сам виджет рассчитывает меняющийся код локально на устройстве. Сервер бота нужен для создания карточки, а не для последующего расчёта кодов. Переписку можно открыть с другого устройства, где доступен Telegram с поддержкой виджетов.

Но у такого удобства есть цена. Секрет проходит через обработчик бота и остаётся в сообщении: тот, кто получил доступ к переписке или устройству, может получить ключ и вычислять будущие коды. Поэтому отдельно сохраните резервную копию ключа и коды восстановления.

Как я написал в [README проекта](https://github.com/talgatiko/telegram-totp-widgets):

> **Бот небезопасен, это полное говно по безопасности, не используйте его!**

Я сделал его для тех, кто хочет пользоваться кодами прямо в Telegram и не хочет ничего дополнительно устанавливать. Но моё желание — чтобы эта возможность стала частью самого Telegram:

> Павел и ко, ~~верни стену~~, пожалуйста, реализуй этот функционал в Telegram, в «Избранном»: если в сообщении есть ссылка на TOTP, отображать её как виджет.
