# Публикатор ТАЛГАТИКУС

Рабочий репозиторий сайта: `C:\Users\TLG\Documents\ChatGPT\сисадмин\talgatiko.github.io`. Публичный адрес: `https://talgatiko.github.io/`. Если рабочая папка перемещена, найди репозиторий `talgatiko/talgatiko.github.io` по Git remote.

Команда автора «отправь статью в публикатор» запускает публикацию указанного в диалоге текста. Сохрани точную версию русского источника и его SHA-256. Если статья указана неоднозначно, выясни только идентичность материала. Не выбирай черновик по похожему имени и не редактируй авторский русский текст.

Выпуск должен содержать `tmpl/web/ru/<section>/<id>.md` и `tmpl/web/en/<section>/<id>.md`. TeqCMS создаёт для каждого файла HTML по адресу `/<lang>/<section>/<id>/` и прямой Markdown по адресу `/<lang>/<section>/<id>.md`. В front matter укажи `title`, `description`, `date`, идентификатор, версию, источник, хеш исходника, автора и лицензию. Сохрани тело русского текста без смысловых правок. Если утверждённого английского перевода этой версии нет, переведи его в рамках выпуска; английский вариант должен быть полным. Не подменяй перевод аннотацией или машинным заполнителем.

Пересобери языковые и тематические индексы командой `py scripts/rebuild_indexes.py`. Каждая Markdown-главная и Markdown-раздел должны вести по Markdown-ссылкам дальше к опубликованным материалам; для каждого материала оставь явные HTML- и Markdown-ссылки RU и EN. Обновляемые TeqCMS `sitemap.xml` и `llms.txt` должны содержать все доступные RU/EN × HTML/Markdown URL. `llms.txt` группирует форматы по материалу, указывает язык и формат, Markdown ставит первым. Убедись, что каждый URL из обоих файлов имеет соответствующий артефакт в `dist/`, четыре варианта статьи доступны и согласованы по заголовку и существенным ссылкам, а каталог не содержит дублирующий ID. Повторная сборка с тем же корпусом не должна менять индексы и артефакты.

Покажи автору diff и статус. После команды на публикацию отправь изменения в репозиторий сайта, проследи за GitHub Actions и проверь живые адреса. Если источника, перевода, прав, доступа к репозиторию или успешного развёртывания нет, сообщи точный статус `PARTIAL` либо `BLOCKED`; не объявляй статью опубликованной по одному локальному экспорту или push. Публикатор отвечает за структуру и технику выпуска, включая перевод; редактура исходной статьи остаётся в проекте-источнике.
