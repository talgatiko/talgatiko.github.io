# Независимая публикация оригинала и проверка дублей

Дата: 2026-10-29. Прямое поручение автора подтверждено чтением исходного диалога 01a15f84-adf2-7160-9933-9b4abb7760ea. Второе поручение — публикация v4 «Нейросеть, которую можно развивать сообща» — подтверждено в 01a14cc4-4c01-7371-9db8-73b305a16e9f.

## План и критерии

1. Перед каждым выпуском сопоставить исходники, живой каталог, маршрут, заголовок, встроенный Markdown и доступный source_sha256. Уже опубликованный точный текст — подтверждённый URL без нового коммита. Отличающаяся версия — прежний маршрут, явное отличие и разрешение замены.
2. Оригинал выпускается независимо; по умолчанию переводчики не вызываются. Переводы — отдельные явно выбранные этапы с проверенным базовым оригиналом. Отсутствующие переводы не создают языковых ссылок.
3. Сохранить все утверждённые источники и SHA-256; лицензии не выбирать за автора. Незаданная лицензия пропускается, свободные права не приписываются.
4. Обновить навык только после обязательной проверки SkillSpector и смыслового разбора с PASS.
5. Проверить локальную сборку, опубликовать только разрешённые файлы, дождаться Actions и проверить живые тексты, языковые ссылки и Mermaid второй статьи.

## Реализация и выполненные проверки

- scripts/existing-publication.mjs: проверка локальных источников и живого JSON-каталога, содержимого страницы; идентичность не определяется одним хешем. Неоднозначные кандидаты и недоступность проверки останавливают выпуск.
- scripts/publish-final.mjs: base_language по умолчанию ru; отдельный --language en/zh только после подтверждённого оригинала. По умолчанию никаких вызовов translate. Проверка перед сборкой и повторно перед Git; замена отличается от точного повтора. Источники/манифест защищены SHA, паузы сохраняются, commit ограничен одним языковым файлом.
- scripts/translation-stage.mjs: переиспользован проверенный модуль с gpt-6.1-sol для EN и Harness для ZH. Каталог ответа приводится к абсолютному пути, исправляя прежний сбой output-last-message. В этой работе модельные вызовы не выполнялись.
- Навигация уже фильтрует реальные htmlItems; код сайта для этого менять не понадобилось.
- 5 тестов ExistingPublication прошли, проверка типов прошла. Тесты покрывают существующий маршрут, несовпадающее содержимое при одинаковом хеше, сетевой отказ, незаданную лицензию, повторный выпуск без сборки/перевода и запрет перевода до оригинала.
- Пробный --finalize для Субъективации выполнен при CODEX_EXECUTABLE и DSH_EXECUTABLE, указывающих на несуществующие файлы. RU успешно собран, engine=null, translations_started=false. Экспортировано 50 страниц; у статьи только RU alternate.
- По реестру и живому сайту обе переданные статьи ещё не опубликованы. Маршруты: blog/ai-subjectivation и it/open-modular-neural-network.
- Параллельные изменения в основной копии переводят Harness на chatgpt-local/gpt-6-luna. Их авторизация в этом поручении не установлена; они не включены в чистый выпуск и не сбрасывались. Здесь сохранён прежний явный DeepSeek account-route; ZH остаётся отложенным.
