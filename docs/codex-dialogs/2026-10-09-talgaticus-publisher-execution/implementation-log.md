# Публикатор ТАЛГАТИКУС: журнал исполнения

Дата: 9 октября 2026 года. Статус на момент подготовки коммита: **локальная реализация и проверки пройдены; отправка и проверка Pages выполняются по прямому разрешению автора**.

## Выполнено

- Значение sitemap по умолчанию изменено на `both`: TeqCMS перечисляет все доступные HTML- и Markdown-ресурсы.
- `llms.txt` строится из того же каталога ресурсов, что sitemap; группирует страницы по маршруту, подписывает язык и формат, Markdown указывает перед HTML.
- Каталог discovery перечисляет явные локализованные Markdown URL рядом с нейтральными Markdown-адресами и устраняет дубли по формату и URL. Раньше английский `.md` файл существовал в экспорте, но его явный `/en/...md` адрес отсутствовал в sitemap и `llms.txt`.
- Для статического sitemap адреса языковых главных нормализуются в `/ru/` и `/en/`, согласуясь с фактическим расположением `index.html` в экспорте.
- Скрипт перестройки индексов добавляет Markdown-ссылки к разделам и статьям в нейтральную и RU/EN Markdown-навигацию.
- Инструкция навыка публикатора обновлена и в репозитории, и в установленном каталоге Codex: требует полный набор адресов, Markdown-навигацию и проверку артефактов обоих форматов.
- Добавлен узкий тест генератора обнаружения.

## Границы результата

- В этот журнал включены только результаты локального экспорта; статус GitHub Actions и живых URL сообщается отдельно после завершения отправки.
- Проверка не подтверждает фактическую индексацию `.md` поисковиками.
- Раздел `/NSK/ru/` и `/NSK/en/` не создавался: полные утверждённые EN-переводы корпуса НСК ещё не подготовлены.
- Первая попытка запуска CLI через junction разрешила корень исходного checkout. Созданный этой попыткой `dist/` был удалён после проверки времени создания; итоговый экспорт выполнялся с явным `--host-root` worktree и CI-переменными.
