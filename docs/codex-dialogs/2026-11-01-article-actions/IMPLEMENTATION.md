# Кнопки открытия статьи в локальном ИИ-приложении

Дата: 2026-11-01. Утверждённый пользователем вариант внедряется в общий блок reading-end рядом с исходным Markdown и сведениями о публикации.

## Изменения

- Общий chrome.js: Codex, Claude Code, Claude Desktop, копирование полного текста, скачивание полного Markdown через Blob без отдельного публичного MD-URL.
- Для ссылки передаётся выбранная языковая версия, заголовок и канонический URL. Полный подготовленный запрос не превышает 5000 UTF-16 единиц; в лимит входит служебный текст. Если статья не помещается, отправляются начало текста, явная отметка фрагмента и просьба получить полный Markdown из исходной страницы перед обсуждением. При обрезке сохраняются Unicode-пары и по возможности граница абзаца.
- Запросы только заполняют поле ввода приложения; отправляет читатель. В статье не исполняются инструкции при нажатии ссылки. Установка программ, выбор локального каталога и авторизация автоматически не выполняются.
- Копирование не сокращает текст. При отказе Clipboard API предлагается выделенное поле для ручного копирования. Скачивание не ограничено 5000 символами.
- Панель и подсказки локализованы RU/EN. Клавиатурный фокус, aria-label и live-status предусмотрены; Flex-wrap сохраняет компактное оформление.
- Версия общих ресурсов вычисляется по SHA-256 page.js/chrome.js/site.css; HTML ссылается на версионированный загрузчик, CSS/chrome получают тот же query. Каталог страниц загружается без кеширования. Адреса и источники статей не меняются.
- В существующей проверке EditorialExport изменено только ожидаемое имя загрузчика с query-версией. Новые тесты не добавлялись; автоматические тестовые наборы не запускались, поскольку пользователь их не запрашивал.

## Наблюдения при предварительном просмотре

Экспорт npm run export:static успешен. Во встроенном браузере просмотрены короткая русская статья, длинная русская статья и английская версия; панель находится непосредственно под исходником и записью о публикации. Для «Субъективации ИИ» полный запрос содержит 4417 символов. Для длинной RU-статьи фрагментный запрос содержит 4934, для EN — 4616; все три ссылки на каждой странице используют один соответствующий текст. Программы через deep links не запускались; готовность обработчиков на компьютерах читателей не проверялась.

## Основания протоколов

- Codex: https://learn.chatgpt.com/docs/reference/commands#deep-links — codex://threads/new и prompt.
- Claude Code: https://code.claude.com/docs/en/deep-links — claude-cli://open, q, лимит 5000 символов.
- Claude Desktop: https://support.claude.com/en/articles/14729294-open-claude-desktop-with-a-link — claude://claude.ai/new и q.

Документация прочитана при согласовании предложения. Фактический запуск приложений остаётся отдельным действием читателя.

| Риск | Основание | Вероятность | Митигация |
|---|---|---|---|
| Ссылка не откроет локальное приложение | На компьютере читателя нет приложения/обработчика или браузер ограничивает URI | средняя | Явная подсказка, полное копирование и скачивание как независимые способы |
| Фрагмент принят за полную статью | Ограничение длины запроса | средняя | Явная отметка фрагмента, канонический URL и указание прочитать полный источник |
| Часть ресурсов останется старой после выпуска | Браузерный кеш общих файлов | средняя | Общая версия по содержимому ресурсов и некешируемый каталог страниц |

Подтверждение коммита, Actions и живого отображения добавляется после публикации.
