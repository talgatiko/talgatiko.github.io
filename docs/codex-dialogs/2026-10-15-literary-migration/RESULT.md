# ТАЛГАТИКУС: переход на литературное оформление

Дата: 2026-10-15. Основание: автор принял образец и поручил перевести весь сайт, проверить адреса/якоря/RU/EN, опубликовать и открыть главную.

## Выполнено

- Производственная команда `npm run export:static` создаёт тёмное литературное представление. Preview остаётся изолированным в design-preview.
- Одна основная HTML-страница на язык: короткая первая строка с общим загрузчиком, единственный Markdown в textarea#markdown-source и закрывающая строка. Общие локальные CSS/JS и pages.json создают меню, языковые переходы, сведения об источнике и компактную карту. Текст статьи в pages.json не дублируется.
- Сохранены четыре раздела: НСК, ИТ, ИБ, Блог. Главная и блог показывают только новые статьи раздела blog; пока новых записей нет, отображается пустое состояние. Старые статьи не перемещены.
- Все прежние HTML-адреса сохранены. Старые .html-алиасы перенаправляют на основной URL с сохранением query и fragment; отдельные копии тела не создаются.
- Самостоятельные публичные Markdown-страницы прекращены. Все внутренние ссылки направлены на HTML. Исходные .md в репозитории и во внешних исходных репозиториях сохранены.
- Sitemap и llms.txt содержат 45 основных HTML URL; llms.txt объясняет извлечение Markdown без JS. Robots разрешает чтение всем.
- Прежний отсутствующий EN-якорь three-parties добавлен в проекцию перед соответствующим заголовком, без изменения авторского исходника.
- Обновлена инструкция публикатора в репозитории и установленная общая копия навыка.

## Проверки перед публикацией

- BASELINE.json: 81 прежний HTML-файл/адрес, явные якоря, SHA-256 всех 43 исходников.
- LOCAL.json: браузерная проверка всех 45 страниц; 1411 внутренних ссылок, 50 ссылок с фрагментами; все прежние адреса и явные якоря сохранены. RU/EN взаимны; нейтральная главная связывает языковые входы. 38 прежних алиасов доступны, переходы алиасов с якорями проверены в браузере.
- На всех страницах проверена ширина 390 px; длинная строка плюсов в исторической NSK-010 переносится без изменения текста. Markdown доступен без JS. Текст не дублируется HTML-каркасом; внешние ресурсы и ошибки JS не обнаружены.
- Семь регрессионных тестов EditorialExport/RebuildIndexes успешны. Проверка типов успешна после добавления типов к модулю дизайна и уточнения параметров экспортёра.
- Хеши локальных библиотек и лицензий совпадают с manifest: TeXMe 1.2.2, Marked 18.1.1, Mermaid 12.2.0. CDN и внешние шрифты не используются.
- Все 43 исходника побайтно неизменны. При выпуске переписываются только представления и служебные файлы, не авторские тексты.

## Проверка после публикации

Запускается тот же `scripts/check-literary-site.cjs` с SITE_BASE_URL=https://talgatiko.github.io и REPORT_PATH для LIVE.json. Дополнительно сверяются удалённый commit, GitHub Actions, содержимое файлов из сырого HTTP и отсутствие старых .md в sitemap/llms.txt. Live-результат сохраняется после успешного развёртывания.

## Риски и пределы

| Риск | Основание | Вероятность | Митигация |
|---|---|---|---|
| Часть HTML-извлекателей не читает textarea | Статья оформляется браузером из Markdown | средняя | Markdown целиком доступен в исходном HTTP без JS; llms.txt объясняет извлечение. Совместимость со всеми LLM и индексация не заявляются |
| Metadata не видна простому извлекателю без JS | Принятая короткая первая строка; title/lang/canonical/hreflang создаются загрузчиком | средняя | Проверены browser DOM и общий каталог metadata. Поведение конкретных поисковиков проверяется отдельно |
| Прежние .md-закладки перестанут работать | Автор отменил самостоятельные .md-адреса | высокая | Внутренние ссылки и discovery переведены на HTML; оригиналы остаются в GitHub. Старые HTML-адреса сохранены |

MathJax не включён; новый математический рендеринг не заявляется. Индексация поисковиками и цитирование LLM не следуют из успешной HTTP/браузерной проверки.
